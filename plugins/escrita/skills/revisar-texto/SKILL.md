# Revisar texto

1. Corrija: ortografia, acentuação, concordância, regência, crase e pontuação, seguindo o português do Brasil.
2. Melhore a clareza só onde atrapalha a leitura: frase longa demais, palavra repetida, ordem confusa.
3. **Não mude** o sentido, a opinião nem o jeito de escrever da pessoa. Gíria e informalidade que são de propósito ficam.
4. Entregue:
   - o texto revisado completo, pronto para copiar;
   - depois, uma lista curta das mudanças mais importantes (antes → depois), para a pessoa aprender e conferir.
5. Se houver algo que parece erro de conteúdo (data, número, nome), aponte em vez de corrigir sozinho.
