Claude writes [web pages](#/aprender/glossario/site-e-pagina) in [HTML](#/aprender/glossario/html), [CSS](#/aprender/glossario/css) and [JavaScript](#/aprender/glossario/javascript), the languages of websites. You don't need to understand any of that: just ask.

## In chat: instant preview

When it hands you a page, the code block has a **Preview** button: the page opens next to the conversation. You can **download** the file and open it in your browser, or send it to someone.

```experimentar
Create an HTML page with a birthday card for my grandmother Lucy, who is turning 80, with animated confetti and a warm message.
```

```experimentar
Create a party budget calculator on an HTML page: I type in the number of guests and the price per person for food, drinks and sweets, and it shows the total and the cost per guest.
```

Ask for adjustments as much as you like: "change the colors to shades of blue", "make the text bigger", "put a photo in the background".

## In Code mode: projects with several files

For something bigger (a website with several pages, an app that stores data), use Code mode in a folder of its own. With the [folder template](#/aprender/modelo-de-pasta), Claude also follows the quality rules and visual references that come with it.

```experimentar-code
Create in this folder a shopping list app that works in the browser: add items, mark them as bought, group them by supermarket section and remember the list when I close it. Then tell me how to open it.
```

## And to put it on the internet?

Publishing a website (doing the [deploy](#/aprender/glossario/deploy)) is another step, with services like Cloudflare Pages, Netlify or GitHub Pages. Claude explains the path and writes whatever is needed, but the account and the publishing are up to you.
