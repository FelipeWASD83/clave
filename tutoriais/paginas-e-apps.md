O Claude escreve [páginas](#/aprender/glossario/site-e-pagina) em [HTML](#/aprender/glossario/html), [CSS](#/aprender/glossario/css) e [JavaScript](#/aprender/glossario/javascript), as linguagens dos sites. Você não precisa entender nada disso: basta pedir.

## No chat: prévia na hora

Quando ele entrega uma página, o bloco de código tem o botão **Prévia**: a página abre ao lado da conversa. Dá para **baixar** o arquivo e abrir no navegador, ou mandar para alguém.

```experimentar
Crie uma página HTML de um cartão de aniversário para a minha avó Lúcia, que faz 80 anos, com confetes animados e uma mensagem carinhosa.
```

```experimentar
Crie uma calculadora de orçamento para festa numa página HTML: eu digito o número de convidados e o valor por pessoa de comida, bebida e doces, e ela mostra o total e o valor por convidado.
```

Peça ajustes à vontade: "muda as cores para tons de azul", "aumenta a letra", "coloca uma foto de fundo".

## No modo Code: projetos com vários arquivos

Para algo maior (um site com várias páginas, um app que guarda dados), use o modo Code numa pasta própria. Com o [modelo de pasta](#/aprender/modelo-de-pasta), o Claude ainda segue as regras de qualidade e as referências visuais que vêm nele.

```experimentar-code
Crie nesta pasta um app de lista de compras que funciona no navegador: adicionar itens, marcar como comprado, separar por seção do mercado e lembrar a lista quando eu fechar. Depois me diga como abrir.
```

## E para pôr na internet?

Publicar um site (fazer o [deploy](#/aprender/glossario/deploy)) é outro passo, com serviços como Cloudflare Pages, Netlify ou GitHub Pages. O Claude explica o caminho e escreve o que for preciso, mas a conta e a publicação são com você.
